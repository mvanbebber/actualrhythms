# Drum samples

From the Versilian Community Sample Library (VCSL) by Versilian Studios, released CC0
(public domain): https://github.com/sgossner/VCSL

One hit per kit piece, trimmed with a short fade and converted to mono MP3:

- kick.mp3: Bass Drum 1, BDrumNew_hit_v5_rr1_Sum
- snare.mp3: Snare Drum, Modern 1, Snare2_HitSN_v5_rr1_Mid
- tom.mp3: Tom 1 (stick), TomH_HitS_v3_rr1_Mid
- tom-low.mp3: Tom 2 (stick), TomL_HitS_v3_rr1_Mid (also the medium tom, played a minor third higher)
- hihat.mp3: Hi-Hat Cymbal, HiHat_HitC_v3_rr1_Mid (closed)
- hihat-open.mp3: Hi-Hat Cymbal, HiHat_HitO_rr1_Mid (open)
- ride.mp3: Suspended Cymbal 1, susCymb1_hit_mp1
- crash.mp3: Suspended Cymbal 1, susCymb1_hit_f1

`offsets.json` (tools/instrument_offsets.py) holds each sample's onset, loudness and peak.
