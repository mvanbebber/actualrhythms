# Piano samples

Salamander Grand Piano V3, recorded by Alexander Holm (Yamaha C5 grand),
licensed CC BY 3.0: https://creativecommons.org/licenses/by/3.0/
Source: https://archive.org/details/SalamanderGrandPianoV3

MP3 encodings from the @audio-samples/piano-mp3-* npm packages by Jan Forst
(https://github.com/darosh/samples-piano-mp3, MIT, see LICENSE-packaging.txt).

- v6, v8, v10, v13: four of the sixteen velocity layers, one file per sampled
  key (every minor third, A0 to C8). Files renamed from e.g. `D#4v10.mp3` to `v10/Ds4.mp3`.
- release/relN.mp3: key-release (damper) sound for piano key N (1 = A0).
